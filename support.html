Support

Need help with StudySprint AI? You can report a problem or suggest an improvement through our GitHub issue tracker.

Open a support request

To help us troubleshoot, tell us which feature you used (quiz, flashcards, or study plan), what you expected, and what happened.

Protect your information

GitHub issues can be public. Never post passwords, personal information, confidential study notes, API tokens, or other sensitive data in a support request.

Common troubleshooting tips

  • If generation fails, try shorter or clearer notes and fewer questions.
  • Make sure StudySprint AI is running within Anna.
  • If an answer seems inaccurate, verify it against your class materials.

If the support button does not work, the repository may not yet exist or GitHub Issues may be disabled. The developer will enable Issues during publishing.
